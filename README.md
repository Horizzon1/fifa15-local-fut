# FIFA 15 Local FUT

A local Ultimate Team server for FIFA 15 PC. Runs a localhost Blaze + FUT HTTP server so the game's Ultimate Team mode works fully offline: packs, squad building, transfer market, persistent club.

## Status

Early development. See [PROGRESS.md](PROGRESS.md) for the live status.

## Credits

This project is a clean-room reimplementation for FIFA 15, heavily informed by the architecture of
[FIFA-14-Local-FUT](https://github.com/KyroGeorge2/FIFA-14-Local-FUT) by KyroGeorge2 —
the proven Blaze/FIRE + FUT HTTP + local identity design for FIFA 14. Thank you.

## Requirements

- A legitimate FIFA 15 PC installation (not included).
- Windows, Python 3.11+.

No game files, executables, or EA assets are included in this repository.
